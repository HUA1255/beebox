# 分段改为句子级，新增段落作为阅读与导出单位

Epic #16 修订转写稿的文本结构契约：分段 (Segment) 改为句子级切分（句末标点优先，其次停顿，最后是长度上限兜底），并新增段落 (Paragraph)。段落由若干同一说话人的分段组成，任务内从 1 起连续编号，段内说话人唯一；目标长度 10–120s，120s 硬上限依次用句末标点、0.8s 停顿和分段边界回退，10s 软下限只向同说话人的相邻段落合并。任何编辑路径（批量保存、新增、删除、切分、合并）保存后都会按同一分组规则重新分段，使编号连续且段内说话人唯一。TXT 与 Markdown 按段落渲染，段首时间取该段第一个分段；SRT 仍按分段一条。导出格式见 `/v1/jobs/{job_id}/exports/{format}`，契约以仓库根目录的 `openapi.json` 快照为准。

**Consequences**

- 前端详情页按段落成块展示，分段仍是编辑与播放高亮的单位。
- `paragraph` 成为 Segment 契约的一部分；`null` 只表示旧任务或尚未分组的中间状态，编辑保存后不再产生。
- 恢复历史版本按快照原样恢复段落编号，不重新分组；快照与当前分组可能因此不同。
- 分组只读说话人与时间，纯文本编辑不会改变已稳定的段落划分。
- 翻译导出仍按分段一行，不套用段落模板。
