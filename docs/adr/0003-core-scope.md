# v1 只做转写核心闭环

v1 的范围限定为转写核心闭环：上传录音、语音转文字、说话人分离、时间戳、校对（播放器联动、说话人改名、文本编辑）与导出 TXT/Markdown/SRT。按 3 小时录音设计、容忍 6 小时；不做性能基准测试，只用真实录音做功能验收。会议纪要自动生成、实时录音、翻译、全文搜索/RAG、多人协作、对外 API、DOCX 导出均不在 v1。

**Consequences**

- 会议纪要由外部工具基于导出的转写稿生成，不进入本服务。
- 说话人只做匿名聚类与改名，不做声纹身份识别。
- 核心闭环的识别、分离、校对与导出必须先达到可用质量，再考虑扩展。
- 不做 RTF、显存曲线等性能测试；仍须保证 16GB 显存内不 OOM、82.7 分钟测试录音能完整跑通。
- DOCX 需求可忽略；需要 Word 时由外部工具从 TXT/Markdown 转换。
