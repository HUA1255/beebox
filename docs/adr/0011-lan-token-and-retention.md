# 局域网访问强制 token，媒体用完即删

BeeBox 绑定局域网 / Tailscale 地址供 home 调用，因此必须配置 Bearer token 才能启动（只监听 127.0.0.1 时除外），不再接受 query 参数里的 token。任务成功后删除源媒体与临时音频，只留结果；结果保留到调用方删除或 30 天后自动清理。原件已由 home 存到 NAS，结果已写进 Obsidian，BeeBox 不承担长期存储。

**Consequences**

- 取代 ADR-0006（仅本机访问、不自动清理）；模型目录约定见 ADR-0010。
- 失败任务若源媒体已被清理，调用方需要重新提交。
- 下载凭证（B 站、YouTube cookie）对 API 调用方只写不读：接口不回显内容、日志不记录、不进数据库；内部每日刷新流程仍会读取 B 站 cookie 文件以完成续期（ADR-0012），这是唯一的内部读取路径。
